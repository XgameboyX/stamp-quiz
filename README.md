**在线玩：<https://xgameboyx.github.io/stamp-quiz/>**

看 6 张邮票照片，判断它属于 **特种邮票 / 纪念邮票 / 普通邮票**，每题限时 5 秒，超时自动公布答案。

## 玩法

- 5 秒倒计时圆环，走完自动揭晓并记为「超时未作答」
- 键盘 `1` `2` `3` 抢答，`空格 / 回车` 下一题
- 答对 100 分 + 剩余秒数 × 20 的速度加成（单题上限 200，满分 1200）
- 结束页有逐题回顾；每局题目顺序随机
